# O que é a INFOCO

A INFOCO é uma plataforma global onde qualquer pessoa pode participar através de vídeos, músicas e interação em tempo real.

A plataforma foi criada para conectar pessoas, culturas e ideias, permitindo que conteúdos sejam descobertos de forma natural, sem depender de algoritmos manipuladores.

Seu principal objetivo é gerar pertencimento, participação e visibilidade para todos.
